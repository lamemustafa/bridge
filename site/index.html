Bridge installs as a local extension. Claude starts it on your computer, and Bridge calls Tally's local HTTP gateway over loopback.

Supported today: Windows x64 and Apple Silicon Mac. Intel Mac and other platforms are not yet qualified.

2. Install and connect

No terminal or configuration file required

  1. Open the downloaded .mcpb file. In Claude Desktop, choose Settings → Extensions → Advanced settings → Install Extension… if your computer does not open it automatically.
  2. Keep the Tally host as localhost. Bridge accepts only a local loopback connection; it does not expose Tally to the internet.
  3. Set Tally port to the port used by Tally's local HTTP gateway, then finish the extension setup.
  4. Restart Claude Desktop if the extension is installed but its tools do not appear. Use Connectors in a new chat to check that Bridge is connected.

Use 9000 unless Tally's local HTTP gateway is configured for another port.

This is Tally's HTTP gateway port, not a Tally licence port. Changing it tells Bridge where to call Tally; it does not change Tally's own setting. Save the extension setting and restart Claude Desktop after changing it.

What stays where

Bridge is local. Your AI conversation is not necessarily local.

Bridge runs on this computer and reads only the configured local Tally endpoint. When you ask Claude to use Bridge, the selected Tally results are sent to the AI provider you chose for that conversation. Choose a redaction setting during installation if you need it, and do not install a package from an untrusted source.

Upgrade or remove it

Private MCPB downloads do not update automatically. To upgrade, download a newer compatible release and install it from Claude Desktop's Extensions settings, then confirm its version and settings. To remove Bridge, use that same Extensions screen and choose uninstall. Removing the extension does not change Tally's gateway setting.
