Ask Claude who owes you, and how old the bills are.

ComplyEaze Bridge reads the TallyPrime already running on this computer, over Tally's own local gateway: outstanding receivables and payables with ageing, and a trial balance, ledger movement or vouchers for a date range you choose.

The only voucher type it posts is a Journal, and that posting waits for your approval in a separate dialog. The assistant cannot approve it.

Install and connect

First, switch Tally's gateway on. TallyPrime does not listen for ComplyEaze Bridge by default. In Tally's connectivity / client-server configuration settings, set Tally to act as a server ("acts as Both" in Tally's own words) and note its HTTP gateway port. To confirm it is listening, open http://localhost:9000/status in a browser, substituting your port: a running gateway answers with a short Tally XML response. If the browser cannot connect at all, the gateway is usually still off, except when Tally runs in a Windows virtual machine on a Mac or the forwarding in step 3 is not set up yet. Read the two cases below before you change any Tally setting.

Two cases where a failed check does not mean the gateway is off

On a Mac with Tally in a Windows virtual machine, run the check inside that VM, or only once the local forwarding in step 3 below is working. A Mac browser that cannot connect may mean that forwarding is missing rather than that the gateway is off.

If the page hangs instead of refusing the connection, Tally may simply be busy behind another request. Wait and retry rather than changing the setting.

  1. Open the downloaded .mcpb file. In Claude Desktop, choose Settings → Extensions → Advanced settings → Install Extension… if your computer does not open it automatically.
  2. Keep the Tally host as localhost. ComplyEaze Bridge accepts only a local loopback connection; it does not expose Tally to the internet.
  3. On a Mac, Tally must already be available on localhost through a local Windows VM or organization-approved local forwarding. A separate PC or LAN-only Tally cannot be reached by entering its network address.
  4. Set Your Tally port to the HTTP gateway port you switched on above, then finish the extension setup.
  5. Restart Claude Desktop if the extension is installed but its tools do not appear. Use Connectors in a new chat to check that ComplyEaze Bridge is connected.

Use 9000 unless Tally's local HTTP gateway is configured for another port.

Enter this only once you have confirmed the gateway is on. It is Tally's HTTP gateway port, not a Tally licence port. This webpage does not save or change any setting. Enter the value in Claude Desktop's extension setup, then restart Claude Desktop after changing it.

ComplyEaze Bridge is local. Your AI conversation is not necessarily local.

ComplyEaze Bridge runs on this computer and connects only to the configured local Tally endpoint. Journal preparation and posting are available by default; every new posting requires your approval in a separate dialog. Payment, Receipt and Contra vouchers are prepared as a file for you to import in Tally yourself, so ComplyEaze Bridge never posts those three. Turn off Allow Journal posting in the extension settings for a read-only connector. When you ask Claude to use it, the selected Tally results are sent to the AI provider you chose for that conversation. Choose a redaction setting during installation if you need it, and do not install a package from an untrusted source.

Upgrade or remove it

Private MCPB downloads do not update automatically. To upgrade, download a newer compatible release and install it from Claude Desktop's Extensions settings, then confirm its version and settings. To remove ComplyEaze Bridge, use that same Extensions screen and choose uninstall. Removing the extension does not change Tally's gateway setting.
